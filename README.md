# LOGIC SERIES OF EXERCISES IN C 

## EXERCISES BY ORDER : 

* **Exercise 1**: fichier.c (Dynamic Age Calculator)
An optimization of a basic static program that dynamically retrieves the current year from the system clock using `<time.h>` and prompts the user for their birth year to calculate their exact age.

* **Exercise 2**: majorite.c
Developed an optimized C program using `unsigned int` and strict `scanf` return validation to safely handle age inputs. It robustly prevents crashes and logical errors by verifying input correctness and filtering out biologically impossibleages.

* **Exercise 3** : calculatrice ( calculator / operator ) 
* **Exercise 4** : cinema ( float / switch ) 
* **Exercise 5** : securite ( do / while )
